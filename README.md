# 🐕SISTEMA DE ADOÇÃO
Seja bem-vindo ao meu projeto SENAC sobre um sistema de adoção para pets!
#### ✅Status: Finalizado.
## 💻Tecnologias aplicadas no projeto.
- Java
- MySql
- HTML
- CSS
- JAVASCRIPT
- SPRING BOOT
## 🧑‍💻Time de desenvolvedores.
Gabriel Correa Macedo.
## 💫Objetivos do projeto.
Este projeto tem como principal objetivo o cadastro dos animais para a adoção do mesmo. 
## 🛠️Funcionalidades do sistema.
- Cadastro de usuário.
-  Cadastro de pet.
- Listagem dos pets disponíveis para adoção.
- Informações do pet (Adotado ou não).
- Informar se o pet faz parte de um abrigo ou não.
